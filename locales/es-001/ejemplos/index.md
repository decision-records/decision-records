Notas sobre este índice:

* Cada ejemplo es un archivo autónomo, la misma convención que se recomienda para su propia bitácora de decisiones.
* El estado, la fecha y quien decide están rellenados en cada ejemplo, para modelar lo que un registro real debería incluir siempre.
* Se representan dos plantillas de forma deliberada: la completa para decisiones de más riesgo y con múltiples partes interesadas; la ligera para decisiones cotidianas y acotadas. Véase [template/index.md](../plantilla/index.md#elegir-qué-plantilla-usar) para saber cómo elegir.
* Se incluye un ejemplo tecnológico aunque el público objetivo sean a la vez líderes de negocio, de tecnología y de estrategia: las decisiones de arquitectura son un caso de este mismo patrón general, no una disciplina aparte.

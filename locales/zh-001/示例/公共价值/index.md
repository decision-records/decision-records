# 在服务重新设计中权衡公共价值

* 状态：已接受
* 日期：2026-06-18
* 决策者：司长，经部门委员会同意
* 负责人：服务设计主任

## 背景

我们的机构每年处理约 400,000 份福利申请。申请处理时间的中位数为 38 天，近期一项审查发现，等待时间最长的，恰恰是最难完成在线表格的人：老年人、英语能力有限的人，以及没有可靠互联网接入的人。一项提案拟将所有申请转为纯数字化服务，并关闭四个地方办事处中的两个，预计可节省 14% 的运营成本。由于这是一项公共服务，仅仅高效是不够的：它还必须是正当的、公平的，并且是我们可以持续的，这正是公共价值战略三角的三个组成部分（合法性与支持、所创造的公共价值，以及运作能力）。

## 考虑过的方案

* **纯数字化服务，关闭两个地方办事处。** 带来最大的节省，对使用者而言处理时间中位数最快，但它把负担转嫁给最难承受的人，并且很可能遭到地方代表的强烈反对，从而削弱合法性与支持。
* **数字优先的服务，保留协助渠道。** 数字渠道为默认，但四个办事处作为协助数字化中心继续开放，并保留电话渠道。带来大部分处理方面的好处，同时保护了可及性，但节省要少得多，约为 5%。
* **保持现有组合并加以改进。** 只做流程改进。风险最低，也没有可及性方面的顾虑，但 38 天的中位数基本不变，也没有利用数字工具所提供的机会。

## 决策

我们将建设数字优先的服务，并把四个办事处保留为带电话渠道的协助数字化中心。我们将依据公共价值，而不只是节省，来评判这次重新设计：处理时间的中位数、服务最慢与最快的群体之间处理时间的差距、一次申请成功的数量，以及节省额。

## 后果

* 服务设计主任将公布这些衡量指标，并每季度向部门委员会和公众报告，包括各申请人群体之间的差距。
* 我们接受较小的节省（约 5%，而不是 14%），以换取公平的可及性，以及与地方代表和申请人之间的合法性。
* 我们将与目前等待时间最长的申请人共同设计协助数字化服务，并公布我们所学到的东西。
* 只有在获得第一年关于谁使用哪条渠道的数据之后，我们才会重新审视办事处网络，任何关闭办事处的提议都将是一项新的决策。
* 运作能力：协助渠道需要受过培训的员工，因此培训在上线前就得到资金，而不是事后才补上。

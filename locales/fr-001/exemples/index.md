# Exemples

Des points de départ pour les équipes qui envisagent un type de décision, dans différentes fonctions de l'entreprise. Chaque exemple utilise le [modèle complet](../modele/index.md#modèle-complet) et est un travail en cours avec le statut `demande de commentaires` : il montre comment une équipe progresse, débat des options et recueille des informations. Aucun ne consigne une décision finale. Lisez-en un ou deux proches de votre domaine, puis remplacez le contexte fictif par le vôtre. Consultez plutôt le [tutoriel](../tutoriel/index.md) pour un parcours guidé.

Notes sur cet index :

* Chaque exemple est un fichier autonome, la même convention que celle recommandée pour votre propre journal des décisions.
* Chaque exemple a le statut `demande de commentaires` et une section Décision qui dit « Pas encore décidé ». Les exemples montrent comment une équipe cadre le problème, vérifie ses hypothèses, compare des options et décide comment elle va décider, et non quoi décider.
* Les détails sont volontairement génériques. Les effectifs, les devises et les prix sont omis ; chaque exemple décrit comment l'équipe de décision pourrait estimer coûts, bénéfices et arbitrages selon ses propres termes.
* La section Notes liées de chaque exemple liste des sources pour en savoir plus : articles de Wikipédia, normes ISO, vidéos et autres références.
* Chaque exemple utilise le modèle complet, pour que vous voyiez chaque section à l'œuvre. Pour les décisions courantes, le [modèle allégé](../modele/index.md#modèle-allégé) ne garde que les champs essentiels ; voir [modele/index.md](../modele/index.md#choisir-le-modèle-à-utiliser) pour savoir comment choisir.
* Un exemple technologique est inclus même si le public visé réunit dirigeants d'entreprise, de technologie et de stratégie : les décisions d'architecture sont une instance de ce même modèle général, pas une discipline à part.

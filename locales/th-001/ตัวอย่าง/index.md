# ตัวอย่าง

จุดเริ่มต้นสำหรับทีมที่กำลังพิจารณาการตัดสินใจประเภทหนึ่งในหน้าที่ต่างๆ ของธุรกิจ ตัวอย่างแต่ละเรื่องใช้ [แม่แบบแบบครบถ้วน](../แม่แบบ/index.md#แม่แบบแบบครบถ้วน) และเป็นงานที่กำลังดำเนินอยู่ด้วยสถานะ `ขอความเห็น` ซึ่งแสดงให้เห็นว่าทีมก้าวหน้า โต้แย้งตัวเลือก และรวบรวมข้อมูลอย่างไร ไม่มีเรื่องใดบันทึกการตัดสินใจที่เสร็จสิ้นแล้ว อ่านหนึ่งหรือสองเรื่องที่ใกล้เคียงกับสาขาของคุณ แล้วแทนที่บริบทสมมติด้วยบริบทของคุณเอง หรือดู [บทเรียน](../บทเรียน/index.md) สำหรับแนวทางทีละขั้นตอน

* [เข้าสู่ส่วนตลาดระดับกลาง](การเข้าสู่ตลาดใหม่/): กลยุทธ์
* [เลือกแพลตฟอร์มซีอาร์เอ็ม](การเลือกผู้ขายซีอาร์เอ็ม/): การขาย
* [วางตำแหน่งแบรนด์ใหม่โดยเน้นความน่าเชื่อถือ](การวางตำแหน่งแบรนด์ใหม่/): การตลาด
* [ราคาตามการใช้งาน](การเปลี่ยนโมเดลราคาผลิตภัณฑ์/): ผลิตภัณฑ์
* [นโยบายทำงานระยะไกลแบบผสมผสาน](นโยบายทำงานระยะไกล/): ทรัพยากรบุคคล
* [ลดความเสี่ยงจากการกระจุกตัวที่ผู้ขายรายเดียว](การพึ่งพาผู้ขายรายเดียว/): ความเสี่ยง
* [สร้างเองหรือซื้อสำหรับโครงการ](สร้างเองหรือซื้อโครงการ/): โครงการ / การดำเนินงาน
* [กรอบงานธุรกิจ](กรอบงานธุรกิจ/): กลยุทธ์ / การดำเนินงาน
* [เลือกฐานข้อมูลหลัก](การเลือกฐานข้อมูล/): เทคโนโลยี / สถาปัตยกรรม
* [โมเดลการดำเนินงานเป้าหมาย](โมเดลการดำเนินงานเป้าหมาย/): กลยุทธ์ / การดำเนินงาน
* [เลือกโมเดลการทำงานแบบผสมผสาน](ตัวเลือกการทำงานแบบผสมผสาน/): ทรัพยากรบุคคล
* [เลือกระหว่างธุรกิจผลิตภัณฑ์กับธุรกิจบริการ](ธุรกิจผลิตภัณฑ์หรือธุรกิจบริการ/): กลยุทธ์
* [ชั่งน้ำหนักคุณค่าสาธารณะในการออกแบบบริการใหม่](คุณค่าสาธารณะ/): ภาครัฐ
* [ชั่งน้ำหนักเศรษฐศาสตร์สุขภาพในการตัดสินใจจัดสรรเงินทุนการรักษา](เศรษฐศาสตร์สุขภาพ/): สุขภาพ
* [วิธีการทำงานที่เป็นลายลักษณ์อักษร](วิธีการทำงาน/): การดำเนินงาน
* [การปรับเปลี่ยนที่สมเหตุสมผลในที่ทำงาน](การปรับเปลี่ยนที่สมเหตุสมผล/): ทรัพยากรบุคคล
* [ITIL 5](itil-5/): เทคโนโลยี / การดำเนินงาน
* [แถลงการณ์แอไจล์](แถลงการณ์แอไจล์/): เทคโนโลยี / การดำเนินงาน
* [ซิกซ์ซิกม่า](ซิกซ์ซิกม่า/): การดำเนินงาน / คุณภาพ
* [การผลิตแบบลีน](การผลิตแบบลีน/): การดำเนินงาน / การผลิต
* [เอ็กซ์ตรีมโปรแกรมมิง](เอ็กซ์ตรีมโปรแกรมมิง/): เทคโนโลยี / วิศวกรรมซอฟต์แวร์
* [การจัดการพอร์ตโฟลิโอโครงการ](การจัดการพอร์ตโฟลิโอโครงการ/): โครงการ / การดำเนินงาน
* [การวางแผนและจัดการสถานที่ทำงาน](การวางแผนและจัดการสถานที่ทำงาน/): การดำเนินงาน / สิ่งอำนวยความสะดวก
* [การจัดการความสัมพันธ์กับผู้ติดต่อ](การจัดการความสัมพันธ์กับผู้ติดต่อ/): การขาย / ลูกค้า
* [เลือกกรอบงานเทคโนโลยีสารสนเทศของเรา](กรอบงานเทคโนโลยีสารสนเทศ/): เทคโนโลยี / การดำเนินงาน

หมายเหตุเกี่ยวกับดัชนีนี้:

* ตัวอย่างแต่ละเรื่องเป็นไฟล์เดียวที่ครบในตัวเอง ซึ่งเป็นข้อตกลงเดียวกับที่แนะนำสำหรับบันทึกรวมการตัดสินใจของคุณเอง
* ตัวอย่างทุกเรื่องมีสถานะ `ขอความเห็น` และส่วนการตัดสินใจที่ระบุว่า "ยังไม่ได้ตัดสินใจ" ตัวอย่างเหล่านี้จำลองวิธีที่ทีมกำหนดกรอบประเด็น ทดสอบสมมติฐาน เปรียบเทียบตัวเลือก และตัดสินใจว่าจะตัดสินใจอย่างไร ไม่ใช่ว่าจะตัดสินใจอะไร
* รายละเอียดตั้งใจให้เป็นแบบทั่วไป จำนวนพนักงาน สกุลเงิน และราคาถูกละไว้ ตัวอย่างแต่ละเรื่องอธิบายว่าทีมตัดสินใจอาจประมาณต้นทุน ประโยชน์ และข้อแลกเปลี่ยนด้วยถ้อยคำของตนเองได้อย่างไร
* ส่วนบันทึกที่เกี่ยวข้องของตัวอย่างแต่ละเรื่องระบุแหล่งเรียนรู้เพิ่มเติม: บทความ Wikipedia มาตรฐาน ISO วิดีโอ และเอกสารอ้างอิงอื่นๆ
* ตัวอย่างทุกเรื่องใช้แม่แบบแบบครบถ้วน เพื่อให้คุณเห็นแต่ละส่วนทำงาน สำหรับการตัดสินใจประจำวัน [แม่แบบแบบเบา](../แม่แบบ/index.md#แม่แบบแบบเบา) เก็บเฉพาะช่องหลัก ดู [แม่แบบ/index.md](../แม่แบบ/index.md#การเลือกแม่แบบที่จะใช้) สำหรับวิธีเลือก
* มีตัวอย่างด้านเทคโนโลยีรวมอยู่แม้ว่ากลุ่มเป้าหมายคือผู้นำด้านธุรกิจ เทคโนโลยี และกลยุทธ์ร่วมกัน การตัดสินใจด้านสถาปัตยกรรมเป็นเพียงกรณีหนึ่งของรูปแบบทั่วไปเดียวกันนี้ ไม่ใช่สาขาที่แยกต่างหาก

# サービスの再設計で公共価値を考慮する

* ステータス: コメント募集中
* 日付: 2026-06-18
* 意思決定者: 事務次官（省の理事会とともに）（要確認）
* オーナー: サービスデザイン部長

概要：作業中です。これは、サービスを再設計していて、効率だけでなく公共価値も考慮したいと考えている公的機関の出発点です。チームが問いをどのように設定し、選択肢を議論し、情報を集めるかを示します。決定は記録されていません。

## 課題

ある公的機関は、多数の給付金の申請を処理しています。申請には長い時間がかかり、最近のレビューでは、最も長く待たされているのは、オンラインのフォームを完成させるのが最も難しい人々、すなわち高齢者、言語能力が限られた人々、信頼できるインターネット接続のない人々であることが分かりました。ある提案は、すべての申請をデジタル専用のサービスに移し、運営コストを節約するために一部の地方事務所を閉鎖するというものです。

これは公共サービスであるため、効率的な選択だけでは十分ではありません。正当で、公正で、機関が持続できるものでもなければなりません。マーク・ムーアの公共価値の戦略的トライアングルは、この 3 つの要素を挙げています。正統性と支持、創出される公共価値、そして運営能力です。

答えるべき問い：

* 誰がサービスを利用しており、各選択肢で誰が取り残されるか？
* 国民は何に価値を置いており、それを提供していることをどう知るか？
* 選挙で選ばれた代表者、申請者、職員、支援者はどう考えており、それはなぜか？
* 機関は実際に何を提供し、持続できるか？

## 前提

それぞれの前提は検証すべきものです。

* **最も長く待たされるのは、デジタル専用のサービスを最も使いにくい人々である。**検証：ルート、時間、特性別に申請を分析し、申請者にインタビューする。
* **支援付きのデジタル対応により、時間をかけて大半の申請者をデジタルのルートに誘導できる。**検証：1〜2 の事務所でパイロットを行い、成果を測定する。
* **閉鎖への反対は、支持を弱める。**検証：地域の代表者や地域団体に早めに相談する。
* **職員は支援業務のためにトレーニングできる。**検証：職員とマネージャーに尋ね、トレーニングの時間を見積もる。

## 制約

* サービスは、効率だけでなく、正当で公正でなければならない。
* 訓練を受けた職員の予算は、開始前に確保しなければならない。
* 事務所を閉鎖する提案は、別の決定でなければならない。
* 不明、要確認：アクセスと平等に関する法的義務、再設計の予算、他の改革の影響。

## 検討した選択肢

各選択肢について、価値、コスト、タイムライン、必要な能力を見積もり、どのような証拠がチームの考えを変えるかを記録します。

* **デジタル専用のサービスとし、一部の事務所を閉鎖する。**
  * 価値：最大の節約。利用できる人にとって最も速い処理。
  * リスク：負担を、それに最も耐えられない人々に移す。強い反対に直面しそうで、正統性が弱まる。
* **デジタルファーストのサービスとし、支援付きのルートを維持する。**デジタルを既定とし、地方事務所は支援付きデジタルのセンターとして残し、電話のルートも維持する。
  * 価値：アクセスを守りながら、処理面の便益の大半を得られる。
  * コスト要因：職員のトレーニング。複数のチャネルの運営。節約が小さい。
* **現在の組み合わせを維持して改善する。**プロセス改善のみ。
  * 価値：リスクが最も低い。アクセスの懸念がない。
  * リスク：長い待ち時間はほとんど変わらず、デジタルの機会を活用しない。
* **モデルを選ぶ前に申請者と共同設計し**、複数のサービスパターンをパイロットでテストする。

## 論拠

チームが想定すべき論点：

* **効率か公平か。**どれだけの節約が、どれだけのアクセスの低下に見合うか？ 誰が決めるか？
* **誰の声が重んじられるか。**申請者、職員、代表者、支援者は、意見が異なるかもしれない。
* **指標。**処理時間の中央値だけでは、不公平が見えなくなることがある。最も遅くサービスを受けるグループと最も速く受けるグループの差が重要である。
* **持続可能性。**機関は、支援付きのサービスを長期にわたり維持できるか？

チームがコストとトレードオフを評価する方法：

1. 社会的なコストと便益を含む費用便益の考え方を使う。たとえば英国財務省のグリーンブックのような公共部門の評価ガイダンスに示されたものである。機関のコストだけでなく、申請者にとっての便益（時間、ストレス、アクセス）も数える。
2. 各選択肢の運営コストと節約を、失敗した申請や再申請の処理コストを含め、範囲で見積もる。
3. 公平とアクセスの指標を加える：グループ間の処理時間の差、最初の試行での成功、ルート別の利用。
4. 戦略的トライアングルの 3 つの要素に照らして選択肢を比較し、評判上および政治上の影響を考慮する。
5. パイロットを行い、名前を付けた指標と判断の時点とともに結果を公表する。

## 決定

**未決定です。**これは出発点です。これを使うチームは、このセクションを自分たちの決定に置き換えてください。

決定に至るための提案：

* 誰が決め、省の理事会が何を見る必要があるかを確認する。
* 先に、公平の指標を含む基準と重みで合意する。
* 上記の証拠を集め、分かったことを記録する。
* 適切であれば公開でコメントを募り、その後決定してステータスを更新する。

## 影響

チームが、支援付きのルートを備えたデジタルファーストのサービスを決めるなら、次のことが必要になります。

* 指標を公開し、グループ間の差を含めて定期的に報告する。
* 開始前に、支援付きのルートのための職員の予算を確保し、訓練する。
* 最も長く待たされている申請者とともに、支援付きのサービスを共同設計し、学んだことを公表する。
* 事務所を閉鎖する提案は、最初の 1 年のデータに基づく新しい決定として扱う。

Notes sur cet index :

* Chaque exemple est un fichier autonome, la même convention que celle recommandée pour votre propre journal des décisions.
* Le statut, la date et le décideur sont renseignés dans chaque exemple, pour modéliser ce qu'un vrai registre devrait toujours comporter.
* Deux modèles sont représentés délibérément : le complet pour les décisions à plus fort enjeu et à parties prenantes multiples ; l'allégé pour les décisions courantes et circonscrites. Voir [template/index.md](../modele/index.md#choisir-le-modèle-à-utiliser) pour savoir comment choisir.
* Un exemple technologique est inclus même si le public visé réunit dirigeants d'entreprise, de technologie et de stratégie : les décisions d'architecture sont une instance de ce même modèle général, pas une discipline à part.

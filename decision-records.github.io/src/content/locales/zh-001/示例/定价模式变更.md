# 转向按用量定价

* 状态：征求意见
* 日期：2026-04-05
* 决策者：产品副总裁，听取 CFO 意见（待确认）
* 负责人：定价与打包负责人

摘要：进行中。这是一个起点，供正在考虑是否从固定的按席位定价转向按使用量收费的模式（或两者的混合）的团队参考。它展示团队如何界定问题、辩论各项方案并收集信息。它不记录任何决策。

## 问题

一款软件产品按席位收费。团队怀疑这让轻度用户付出的多于他们所获得的价值，导致他们流失，同时对大量使用产品的客户收费不足。竞争对手已转向按用量或混合定价，潜在客户也在问公司为什么没有这样做。

需要回答的问题：

* 产品的价值度量是什么：哪种使用量单位与客户获得的价值相对应？
* 轻度客户和重度客户的行为和感受真的如我们所想吗？
* 哪种定价模式最贴合价值，同时让收入保持足够可预测以便规划？
* 现有客户将如何公平地转到新模式？

## 假设

每条假设都需要检验。

* **使用量是价值的良好代表。** 检验：在一系列账户中，把使用量与客户成果和满意度对比。
* **轻度用户因为觉得价格太高而离开。** 检验：查看取消原因，并与已流失的轻度用户交谈。
* **重度用户会为更多价值支付更多。** 检验：抽样询问他们的支付意愿，并检验他们对价格变化的敏感程度。
* **我们可以准确、透明地计量并计费。** 检验：检查数据质量，并询问客户是否能预测自己的账单。

## 约束

* 任何现有客户都不应在没有提前通知的情况下面临净涨价。
* 销售薪酬计划必须在新结构用于新交易之前反映这一变化。
* 财务需要能够应对随用量波动的收入的预测模型。
* 未知，待确认：锁定价格的合同条款、计费系统能做什么，以及竞争对手的详细价格。

## 考虑过的方案

对每个方案，估计价值、成本、时间安排和所需能力，并记下哪些证据会让团队改变想法。

* **保留固定的按席位定价。**
  * 价值：简单；无需迁移。
  * 风险：轻度客户流失和定价不足的问题依然存在；竞争对手各有不同。
* **完全转向按用量定价。**
  * 价值：价格紧贴价值；入门门槛低。
  * 成本驱动因素：计量、计费和报表系统；账单疑问的支持；销售方面的变化。
  * 风险：收入波动；不喜欢账单难以预测的客户。
* **混合：基础费用加按用量收费。**
  * 价值：收入比纯按用量模式更可预测，同时兼顾轻度和重度用户。
  * 成本驱动因素：同上，再加设计的复杂性。
  * 时间安排形态：先是新客户；现有客户在受保护期之后转换。
* **带用量上限的分级套餐。** 一种更简单的折中路径，可能满足大部分需求。
* **先试验**，把新模式提供给一部分新客户或某个细分领域，然后比较。

## 论证

团队应预料到的争论点：

* **可预测性还是公平性。** 客户和财务看重可预测的账单；按用量定价显得更公平，但会波动。
* **用哪个度量？** 席位、调用、记录，还是成果？糟糕的度量会引发错误的行为。
* **迁移。** 沿用旧条款保护了客户，却推迟了收益并使运营复杂化。
* **竞争。** 追随竞争对手本身不是理由。我们自己的证据怎么说？

团队可以如何评估成本与权衡：

1. 利用现有客户数据为每个方案建模收入：每个账户在新模式下会付多少？以区间形式展示赢家和输家以及离散程度。
2. 定性地并通过测试估算价格弹性，并考虑客户对账单变化的反应。
3. 为这一变化估价：计量、计费、支持、销售培训、法务和合同变更、预测工具。
4. 在收入水平、收入稳定性、对客户的公平、对增长的影响和复杂性方面比较各方案；检验对假设的敏感性。
5. 规划一次试验，并事先定义什么结果会促使推广、调整或停止。

## 决策

**尚未决定。** 这是一个起点。使用它的团队应以自己的决策取代本节。

建议的决策方式：

* 确认由谁决策，以及谁必须签字同意（例如财务）。
* 先就标准和权重达成一致。
* 收集上述证据并记录发现。
* 分发征求意见，然后做出决策并更新状态。

## 影响

如果团队决定转向混合模式，就需要：

* 为每个现有账户建模，确认没有人面临意外涨价。
* 更新销售薪酬，并培训销售和支持团队。
* 修订收入预测，以应对其波动。
* 尽早联系有流失风险的轻度用户，因为他们的账单应当下降。
* 另行决定具体的超额用量档位和阈值。

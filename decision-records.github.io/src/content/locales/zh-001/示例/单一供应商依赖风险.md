# 降低单一供应商集中风险

* 状态：已接受
* 日期：2026-05-20
* 决策者：首席运营官
* 负责人：采购负责人

## 背景

一项内部风险审查发现，我们 70% 的关键基础设施支出都通过同一家供应商。该供应商上个季度发生了一次非计划的、持续数小时的故障，扰乱了我们面向客户的服务，而且其价格同比上涨了 18%，合同中没有任何上限。照现状继续下去，我们既暴露于可用性风险之下，也暴露于不受约束的成本增长之下。

## 考虑过的方案

* **接受风险，不做任何改变。** 近期没有成本或工作量，但故障风险和不设上限的价格风险都完全保留；风险审查明确指出，在当前集中度下这是不可接受的。
* **重新谈判现有合同以获得更好的服务水平协议和价格上限，仍用单一供应商。** 解决了价格风险并改善了问责，但没有降低再次发生故障时的单点故障风险。
* **分散化：在两个季度内把 25% 的关键工作负载迁到第二家供应商，并为其余 75% 重新谈判主要供应商的合同。** 在显著降低集中风险的同时，避免了完全迁移的成本和干扰；也增强了我们对主要供应商的谈判地位。

## 决策

我们将在未来两个季度内把 25% 的关键工作负载迁到第二家供应商，以实现分散化，并就其余工作负载重新谈判主要供应商的合同，争取服务水平承诺和价格上限。

## 后果

* 采购部将为第二家供应商开展供应商选择流程，使用与最初选择供应商时相同的评估标准。
* 工程 / 运营部门需要规划分阶段迁移，避免过渡期间中断服务。
* 主要供应商的合同将同步重新谈判；分散化工作带来的筹码应当能改善谈判条件。
* 我们接受管理两家供应商所增加的运营复杂性，以换取故障和价格风险的实质性降低。
* 在 25% 的迁移完成之前，采购负责人将在每个季度末向首席运营官报告集中度百分比和重新谈判后的服务水平协议条款。

## 相关

* 本决策直接回应第一季度风险审查的发现；此前没有关于供应商集中度的决策记录可供取代。

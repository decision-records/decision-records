# 采用联系人关系管理

* 状态：已接受
* 日期：2026-10-12
* 决策者：首席营收官
* 负责人：营收运营负责人

## 背景

我们的客户和合作伙伴联系人分散在个人收件箱、个人电子表格和三个不同的工具中。当客户经理离职时，他们的关系也随之而去，我们还曾两次在同一天由不同的团队联系同一个人。我们也无法说明，一个人同意被联系的授权记录在组织中的哪个位置。我们需要一种统一的共享方式来管理联系人以及我们与他们的关系，涵盖客户、合作伙伴和供应商，而不仅仅是销售潜在客户。

## 考虑过的方案

* **保持现有的工具和电子表格混用的状态。** 没有成本或变革的工作量，但关系流失、重复联系和授权不明的问题仍将继续。
* **为全公司采用一个共享的联系人关系管理系统。** 每个人和每个组织一条记录，共享的互动历史，以及被记录的授权。解决了这些问题，但需要数据迁移、关于谁能看到什么的规则，以及客户经理改变习惯。
* **只在现有的销售 CRM 中增加联系人管理。** 最快，而且我们熟悉这个工具，但会把合作伙伴和供应商排除在外，并让非销售团队所持有的联系人保持分离。

## 决策

我们将为全公司采用一个共享的联系人关系管理系统，每个人和每个组织一条记录，共享的互动历史，并把此人的授权和联系偏好记录在该记录上。我们将分阶段迁移，从销售和客户支持团队开始，并在数据迁移完毕后停用其他工具。

## 后果

* 营收运营负责人将牵头选型、数据迁移，以及关于谁可以查看和修改哪些记录的规则。
* 联系方式和授权将记录在同一个地方，任何人要求查看、更正或删除其数据的请求，都将从该记录处理。
* 客户经理应当在系统中记录他们的互动；我们将在第一个季度检查这一点，如果没有做到，就调整流程，而不只是提醒。
* 我们将在迁移期间清理并合并重复的联系人，这需要占用员工时间，我们接受这一点。
* 我们放弃使用个人电子表格的自由，以换取留在公司内部、更易于保护的关系。

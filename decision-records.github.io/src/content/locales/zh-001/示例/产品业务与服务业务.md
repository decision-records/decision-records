# 在产品业务与服务业务之间做出选择

* 状态：已接受
* 日期：2026-07-08
* 决策者：CEO 和董事会
* 负责人：首席战略官

## 背景

我们的大部分收入（68%）来自为中型客户做的定制实施项目，这些项目建立在我们自有的软件平台之上。项目有利润，但难以预测，每个项目都需要资深工程师，因此增长受制于招聘。越来越多的合作伙伴不借助我们的服务而直接使用我们的平台，投资者也在问我们究竟是一家产品公司还是一家服务公司。这个答案会改变我们招聘什么人、如何定价、如何衡量成功，以及我们对客户说什么。

## 考虑过的方案

* **成为产品业务。** 以订阅方式销售平台，配以标准化入门，并把定制工作转介给合作伙伴。提供经常性收入和不依赖人员数量的增长，但在转型期间收入会下降大约两年，而我们最好的客户看重定制工作。
* **继续做服务业务。** 继续销售实施项目，把平台当作交付项目的工具。保住了我们现有的收入和客户关系，但让我们暴露于招聘上限，以及以更低价格在我们的平台上交付项目的合作伙伴面前。
* **两者并行，经济核算分开。** 把服务保留为一条独立的业务线，有自己的目标，而产品线有自己的路线图、定价和衡量指标。在打造产品业务的同时保住当前的收入，但会分散注意力，并有可能让两条业务线都投入不足。

## 决策

我们将用三年时间成为产品业务。我们将转向订阅定价和标准化入门，分阶段把面向客户的实施工作转移给合作伙伴网络，并为战略客户保留一支小型的服务团队。我们将每年对照订阅收入、毛利率和客户留存复审该计划。

## 后果

* 首席战略官将公布三年计划，包括各客户细分领域转向订阅定价的顺序。
* 我们预计总收入在头两年会有所下降；董事会已同意这一点，并同意为弥补它所需的投入。
* 随着实施工作转移给合作伙伴，岗位将发生变化；将由另一项决策记录我们如何支持受影响的人员。
* 我们将用不同的方式衡量自己：年度经常性收入、毛利率和净收入留存率取代项目利用率，成为首要衡量指标。
* 我们放弃对部分客户实施体验的控制，以换取经常性收入和不依赖招聘的增长。

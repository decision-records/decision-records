# Примеры

Каждый пример использует [подробный шаблон](../шаблон/index.md#подробный-шаблон) и представляет собой работу в процессе со статусом `запрос комментариев`: он показывает, как команда продвигается, обсуждает варианты и собирает информацию. Ни один из них не фиксирует окончательного решения. Прочитайте один-два примера, близких к вашей области, затем замените вымышленный контекст своим. Вместо этого см. [учебник](../учебник/index.md) для пошагового разбора.

Замечания к этому указателю:

* Каждый пример — самодостаточный файл, то же соглашение, которое рекомендуется для вашего собственного журнала решений.
* У каждого примера статус `запрос комментариев`, а в разделе «Решение» написано «Пока не решено». Примеры моделируют, как команда формулирует проблему, проверяет допущения, сравнивает варианты и решает, как она будет решать, а не то, что решать.
* Подробности намеренно общие. Численность персонала, валюты и цены опущены; каждый пример описывает, как команда, принимающая решение, могла бы оценить затраты, выгоды и компромиссы в собственных терминах.
* Раздел «Связанные заметки» каждого примера перечисляет источники для дальнейшего изучения: статьи Википедии, стандарты ISO, видео и другие материалы.
* Каждый пример использует подробный шаблон, чтобы вы могли увидеть каждый раздел в действии. Для повседневных решений [лёгкий шаблон](../шаблон/index.md#лёгкий-шаблон) сохраняет только основные поля; как выбрать, см. [template/index.md](../шаблон/index.md#как-выбрать-шаблон).
* Включён один технологический пример, хотя целевая аудитория — руководители бизнеса, технологий и стратегии вместе: архитектурные решения — пример того же общего образца, а не отдельная дисциплина.

# Examples

Starting points for teams that are considering a kind of decision, across business functions. Each example uses the [comprehensive template](../template/index.md#comprehensive-template) and is a work in progress with the status `request for comments`: it shows how a team makes progress, debates the options, and gathers information. None of them records a finished decision. Read one or two close to your own domain, then replace the fictional context with your own. See the [tutorial](../tutorial/index.md) for a guided walkthrough instead.

Notes on this index:

* Each example is one self-contained file — the same convention recommended for your own decision log.
* Every example has the status `request for comments` and a Decision section that says "Not yet decided". The examples model how a team frames the issue, tests assumptions, compares options, and decides how it will decide, not what to decide.
* Details are deliberately generic. Staff counts, currencies, and prices are left out; each example describes how the decision team could estimate costs, benefits, and trade-offs in its own terms.
* The Related notes section of each example lists sources to learn more: Wikipedia articles, ISO standards, videos, and other references.
* Every example uses the comprehensive template, so you can see each section at work. For everyday decisions, the [lightweight template](../template/index.md#lightweight-template) keeps just the core fields; see [template/index.md](../template/index.md#choosing-which-template-to-use) for how to choose.
* A technology example is included even though the target audience is business, technology, and strategy leaders together — architecture decisions are one instance of this same general pattern, not a separate discipline.

# Ejemplos

Puntos de partida para los equipos que están considerando un tipo de decisión, en distintas funciones de la empresa. Cada ejemplo usa la [plantilla completa](../plantilla/index.md#plantilla-completa) y es un trabajo en curso con el estado `solicitud de comentarios`: muestra cómo un equipo avanza, debate las opciones y reúne información. Ninguno registra una decisión final. Lea uno o dos cercanos a su ámbito y luego sustituya el contexto ficticio por el suyo. Consulte el [tutorial](../tutorial/index.md) para un recorrido guiado.

Notas sobre este índice:

* Cada ejemplo es un archivo autónomo, la misma convención recomendada para su propio registro de decisiones.
* Todos los ejemplos tienen el estado `solicitud de comentarios` y una sección Decisión que dice «Aún no se ha decidido». Los ejemplos modelan cómo un equipo enmarca el problema, comprueba supuestos, compara opciones y decide cómo va a decidir, y no qué decidir.
* Los detalles son deliberadamente genéricos. Se omiten las cifras de personal, las monedas y los precios; cada ejemplo describe cómo el equipo de decisión podría estimar costos, beneficios y compensaciones en sus propios términos.
* La sección Notas relacionadas de cada ejemplo enumera fuentes para saber más: artículos de Wikipedia, normas ISO, vídeos y otras referencias.
* Todos los ejemplos usan la plantilla completa, para que vea cada sección en funcionamiento. Para las decisiones cotidianas, la [plantilla ligera](../plantilla/index.md#plantilla-ligera) conserva solo los campos básicos; consulte [plantilla/index.md](../plantilla/index.md#elegir-qué-plantilla-usar) para saber cómo elegir.
* Se incluye un ejemplo tecnológico aunque el público objetivo reúna a líderes de negocio, tecnología y estrategia: las decisiones de arquitectura son una instancia de este mismo patrón general, no una disciplina aparte.
